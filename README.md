# PREMIUM-HAXBALL-CLIENT

The fastest Haxball client, featuring:
- Spotify / YouTube Music support
- Replay watching with extrapolation
- 3 new ball kick sounds
- Custom ball image
- Field flip
- Custom resolution
- Option to hide ping/FPS, menu buttons and the scoreboard
- And much more!

(For now, please keep your FPS limit below 700. I'm working on fixing the stuttering issue.)
